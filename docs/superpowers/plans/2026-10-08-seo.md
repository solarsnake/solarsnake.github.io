# SEO Pass Implementation Plan

> **Execution:** two Sonnet `tim-team:implementer` briefs (Task 1 and Task 2 run in parallel; their file scopes are disjoint). The orchestrator (Opus) reviews each diff, renders the share card, and commits. Steps use `- [ ]`.

**Goal:** Make justthetipp.com findable and shareable. Every page gets a name-first title, a meta description, a canonical URL, a share image and favicons. The home and resume pages get `Person` structured data, and each post gets `BlogPosting` structured data.

**Architecture:**
- Images are generated once by `scripts/make-images.mjs` (via `@resvg/resvg-js`) and committed. CI never renders images.
- Head tags on hand-written pages are edited directly.
- JSON-LD comes from `data/profile.json` at build time:
  - for the home and resume pages, through a new `<!-- build:jsonld -->` marker
  - for posts, inside `renderPostPage`
- No new runtime dependencies.

**Tech stack:** Node 22 `.mjs`, `node:test`, existing `scripts/build.mjs` + `injectBlocks`, `@resvg/resvg-js` (devDependency, exact pin).

**Context:** builds on the site refresh. Spec: `docs/superpowers/specs/2026-10-07-site-refresh-design.md`.

## Global Constraints

- **Branch:** `seo` (created by the orchestrator). Implementers never commit.
- **Site URL:** `https://justthetipp.com`. All canonical and `og:url`/`og:image` values are absolute and use it.
- **Share image:** `https://justthetipp.com/assets/img/og-card.png`, 1200×630 PNG.
- **Favicons:**
  - `/assets/img/favicon.svg`
  - `/assets/img/favicon-48.png` (48×48)
  - `/assets/img/apple-touch-icon.png` (180×180)
- **Name:**
  - **Visible titles** use "Timothy Tippens".
  - **JSON-LD** uses `profile.name` ("Timothy M. Tippens"), plus `alternateName: "Timothy Tippens"`.
- **Never publish** phone numbers, the Gmail address, or `contact.email` in structured data.
- **Meta descriptions** are 120–160 characters, plain text, and HTML-escaped.
- **Design tokens** (from the site): black `#000`, card `#0d0d0d`, border `#1a3a1a`, green `#00ff00` / `#00cc00` / `#008800`, cyan `#00ffcc`. Font: Menlo stack.
- **Existing behaviour must not change:** terminal, keyboard navigation, blog, admin. All existing tests keep passing.

Every one of `index.html`, `resume.html`, `blog/index.html` and `contact.html` must end up with exactly one of each tag below. Values come from the copy table. Edit existing og/twitter tags in place rather than duplicating them.

```html

<link rel="canonical" href="CANONICAL">
<meta property="og:title" content="TITLE">
<meta property="og:description" content="DESCRIPTION">
<meta property="og:url" content="CANONICAL">
<meta property="og:image" content="https://justthetipp.com/assets/img/og-card.png">

<meta property="og:image:height" content="630">
```

`&` inside attribute values must be written as `&amp;`. `404.html` gets only the three favicon links and the robots `noindex` meta. `admin/index.html` is not touched.

## Review Focus

1. **A post title, excerpt or tag containing `"`, `<`, `&` or `</script>`.** JSON-LD must stay valid JSON, and the post must not be able to close the `<script>` early (escape `<` as `\u003c`). Meta attributes must be HTML-escaped. Pinned in Task 2's `seo.test.mjs` and `posts.test.mjs`.
2. **Duplicate head tags.** Two `og:title` or two canonicals on one page would send search engines conflicting signals. Pinned in Task 2's build test, which counts tag occurrences per page.
3. **Absolute vs relative URLs.** LinkedIn ignores a relative `og:image`. Pinned in the build test (every `og:image` and canonical starts with `https://justthetipp.com/`).
4. **The share image is missing or the wrong size in `_site`.** The preview silently breaks. Pinned in Task 1 (PNG header dimensions) and Task 2's build test (file exists in `_site`).
5. **A drafted or unpublished profile field is missing** (for example no `education`). JSON-LD generation must omit that key, not crash. Pinned in Task 2's `personJsonLd` minimal-profile test.

```js
import { SITE_URL, postUrl } from './util.mjs';

export const OG_IMAGE = `${SITE_URL}/assets/img/og-card.png`;

export function jsonLdScript(obj) {
  return `<script type="application/ld+json">${JSON.stringify(obj).replace(/</g, '\\u003c')}</script>`;
}

export function personJsonLd(p) {
  const out = {
    '@context': 'https://schema.org',
    '@type': 'Person',
    name: p.name,
    alternateName: p.name.replace(/ [A-Z]\. /, ' '),
    url: `${SITE_URL}/`,
    image: OG_IMAGE,
    description: p.headline,
  };
  const current = p.experience?.[0];
  if (current?.roles?.[0]?.title) out.jobTitle = current.roles[0].title;
  if (current?.company) out.worksFor = { '@type': 'Organization', name: current.company };
  if (p.education?.school) out.alumniOf = { '@type': 'CollegeOrUniversity', name: p.education.school };
  const [city, region] = String(p.location || '').split(',').map(s => s.trim());
  if (city && region) out.address = { '@type': 'PostalAddress', addressLocality: city, addressRegion: region, addressCountry: 'US' };
  const sameAs = [p.contact?.github, p.contact?.linkedin].filter(Boolean);
  if (sameAs.length) out.sameAs = sameAs;
  out.knowsAbout = p.featuredSkills || Object.values(p.skills || {}).flat().slice(0, 9);
  return out;
}

export function blogPostingJsonLd(post, authorName) {
  const url = postUrl(post.slug);
  return {
    '@context': 'https://schema.org',
    '@type': 'BlogPosting',
    headline: post.title,
    description: post.excerpt,
    datePublished: post.date,
    dateModified: post.date,
    url,
    mainEntityOfPage: url,
    author: { '@type': 'Person', name: authorName, url: `${SITE_URL}/` },
    image: OG_IMAGE,
    keywords: (post.tags || []).join(', '),
    inLanguage: 'en-US',
  };
}
```
